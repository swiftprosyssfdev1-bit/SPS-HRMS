How it works

  1. Download the Employee Master template for your branch.
  2. Fill one employee per row. Name and D O J are mandatory, and so are both the Emp ID Number and the Enrollment No of an employee that already exists, and both must belong to the same employee. Their existing profile is updated; this page never creates employees.
  3. Validate only to check every row without saving anything.
  4. Validate & Import once the report is clean. If any row has an error, nothing is saved. Up to {{ max_rows }} employees per file.
